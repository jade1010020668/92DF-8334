# 📊 Tablero semanal — Dotaciones El Manantial
## Diego, cada lunes 15 min. Anote 4 números y mire dónde se cae el embudo.

> Los 3 primeros números salen SOLOS del correo de reporte que manda la máquina
> cada lunes 7am. El 4º (ventas) lo cuenta usted de lo que cerró el papá.

---

## El embudo (así se lee)
```
CONTACTADAS  →  RESPONDIERON  →  COTIZACIONES  →  VENTAS
(la máquina)     (~0,5-1%)         (el papá)       (el papá)
```
Cada flecha es un salto donde se puede perder gente. El número que esté "flojo"
dice DÓNDE está el problema.

## 🔎 Si un número está bajo, el problema está en…

| Síntoma | Qué está fallando | Qué hacer |
|---|---|---|
| **Contactadas = 0** | El motor no está enviando | Revisar el Registro: ¿pausado? ¿sin cupo? ¿error? Reactivar |
| **Respondieron muy pocas** (<0,5% con +200 enviadas) | El mensaje o la entregabilidad | Avisarle a Claude para cambiar plantillas; revisar rebotes; considerar dominio propio |
| **Responden pero no hay cotizaciones** | El papá no alcanza a responder rápido | Reforzar la regla de los 5 minutos; ¿le llegan los avisos al celular? |
| **Cotiza pero no vende** | Precio o seguimiento | Revisar precios vs competencia; hacer la 2ª llamada (la app muestra los "sin respuesta") |
| **Rebotes altos** (la máquina se auto-pausó) | Correos muertos en la lista | Limpiar la lista y reactivar; avisar a Claude |

## Meta del mes
- **Mes 1:** 2-3 ventas nuevas (la máquina apenas calienta).
- **Mes 2-3:** 5+/mes (con reseñas, volumen acumulado y seguimiento).

**Si al final del mes no se llegó:** no es fracaso, es diagnóstico. El número flojo
del embudo dice exactamente qué ajustar para el mes siguiente.
